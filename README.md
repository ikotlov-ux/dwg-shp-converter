# DWG ⇄ SHP конвертер (МГГТ ⇄ WGS84)

Утилиты для конвертации геопространственных данных между CAD- и ГИС-форматами
со сменой системы координат **МГГТ Москвы ⇄ WGS84**, включая варианты
`Moscow_bessel ДГИ` из поставок заказчика.

## Состав репозитория

| Папка | Описание |
|---|---|
| `R/` | Исходная версия на R (консольный интерактивный скрипт) |
| `python/` | Python-версия с графическим интерфейсом (tkinter) |

## Поддерживаемые форматы

- **Вход:** DWG, DXF, SHP, GeoJSON, GeoPackage (.gpkg)
- **Выход:** DWG, DXF, SHP, GeoJSON, GeoPackage (.gpkg)

DWG читается и записывается через [ODA File Converter](https://www.opendesign.com/guestfileconverter)
(DWG ⇄ DXF), остальные преобразования выполняет `ogr2ogr` (GDAL, входит в QGIS / OSGeo4W).

## Системы координат

| СК | PROJ-строка |
|---|---|
| WGS84 | `EPSG:4326` |
| МГГТ Москвы | `+proj=tmerc +lat_0=55.66666666667 +lon_0=37.5 +k=1 +x_0=16.098 +y_0=14.512 +ellps=bessel +towgs84=316.151,78.924,589.650,-1.57273,2.69209,2.34693,8.4507 +units=m +no_defs` |
| Moscow_bessel ДГИ (x0=0, y0=0) | `+proj=tmerc +lat_0=55.66666666666666 +lon_0=37.5 +k=1 +x_0=0 +y_0=0 +a=6377397.0 +rf=299.15 +towgs84=316.151,78.924,589.650,-1.57273,2.69209,2.34693,8.4507 +units=m +no_defs` |
| Moscow_bessel ДГИ (смещение x=7.2, y=16.8) | вариант ДГИ с ручной поправкой по контрольной точке |

Параметры перехода датума соответствуют официальному положению МГГТ о ПМСК Москвы
(7-параметрическое преобразование, эллипсоид Бесселя). Вариант `Moscow_bessel ДГИ`
соответствует WKT из файлов заказчика (False_Easting/Northing = 0) с добавленным
`+towgs84`, отсутствующим в исходном `.prj`.

## Возможности (вектор → DWG)

- разбивка на несколько DWG по уникальным значениям поля;
- подписи точек из атрибутов (высота текста настраивается);
- видимые маркеры точек: залитые цветные круги, цвет по значению поля;
- легенда в правом нижнем углу (отступ от объектов ≥ 20 м): маркеры тех же
  цветов и размеров с цифровыми кодами 1, 2, 3…;
- таблица точек в XLSX: лист `points` (все атрибуты + пересчитанные координаты)
  и лист `legend` (код — исходное значение — цвет).

## Быстрый старт (Python-версия)

```bash
cd python
pip install -r requirements.txt
python app.py
```

Требования: Python 3.9+, `ogr2ogr` (QGIS/OSGeo4W), ODA File Converter — только
для чтения/записи DWG. Подробности — в `python/README.md`.

## История версий

Функциональность выросла из рабочего R-скрипта: DWG⇄SHP → произвольные
вход/выход форматы → SHP→SHP со сменой проекции → варианты CRS заказчика (ДГИ)
с контрольной поправкой. Python-версия объединяет всё с графическим интерфейсом.
