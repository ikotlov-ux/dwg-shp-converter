# Геопространственный конвертер DWG / DXF / SHP / GeoJSON / GPKG

Python-версия (с графическим интерфейсом на tkinter, русский язык)
R-скрипта `convert_dwg_to_shp_v21.r`. Конвертирует векторные данные
между форматами DWG, DXF, SHP, GeoJSON и GPKG с перепроецированием
между настраиваемыми системами координат (СК), а также оформляет
выходные DWG: маркеры и подписи точек, легенда, выгрузка таблиц в XLSX.

## Возможности

- Мультивыбор входных файлов (`.dwg .dxf .shp .geojson .gpkg`),
  список файлов с удалением, выбор выходной папки.
- Исходная и целевая СК из списка (или пользовательская PROJ-строка),
  автоопределение исходной СК по `.prj` (паттерн Moscow_bessel ДГИ).
- Выходные форматы: DWG, DXF, SHP, GeoJSON, GPKG.
- Конвертация через `ogr2ogr` (GDAL), DWG — через ODA File Converter.
- Оформление «вектор → DWG/DXF»: маркеры точек (залитые круги,
  цвет по значению поля, категориальная палитра 20 цветов, true color),
  подписи точек, легенда с цифровыми кодами справа-снизу (отступ ≥ 20 м),
  разбивка на файлы по уникальным значениям поля, выгрузка точек в XLSX
  (листы `points` и `legend`).
- Фоновая конвертация: лог процесса, кнопки не блокируются, статус-бар.

## Установка

Требуется **Python 3.9+** (в Windows — с библиотекой tkinter; обычный
установщик с python.org её включает).

```bash
cd python
pip install -r requirements.txt   # ezdxf, openpyxl
```

Для конвертации нужны внешние инструменты (не Python-пакеты):

| Инструмент | Назначение | Где взять |
|---|---|---|
| ogr2ogr (GDAL) | конвертация и перепроецирование векторных форматов | QGIS (https://qgis.org) или OSGeo4W |
| ODA File Converter | чтение `.dwg` на входе и запись `.dwg` на выходе (ACAD2018) | https://www.opendesign.com/guestfiles/oda_file_converter |

Приложение само ищет `ogr2ogr` в типичных путях QGIS/OSGeo4W
(`C:/Program Files/QGIS*/bin/ogr2ogr.exe` и др.) и в PATH; путь к ODA
подставляется по умолчанию `C:/Program Files/ODA/ODAFileConverter/ODAFileConverter.exe`,
оба пути можно изменить в разделе «Инструменты».

## Запуск

```bash
python app.py
```

## Интерфейс (описание)

1. **Входные файлы** — кнопка «Добавить файлы…» открывает Проводник
   с мультивыбором; выбранные файлы видны списком, лишние можно
   удалить. При добавлении `.shp` с `.prj` заказчика ДГИ исходная СК
   автоматически переключается на «Moscow_bessel ДГИ».
2. **Системы координат** — выпадающие списки исходной и целевой СК
   (см. таблицу ниже) и поле пользовательской PROJ-строки.
3. **Выходные данные** — формат (DWG/DXF/SHP/GeoJSON/GPKG) и папка.
4. **Оформление «вектор → DWG/DXF»** — разбивка по полю, маркеры
   (диаметр), цвет маркеров по полю, подписи (поле + высота текста),
   легенда, выгрузка XLSX.
5. **Инструменты** — пути к ogr2ogr и ODA File Converter.
6. Кнопка **«Конвертировать»**, журнал процесса и статус-бар внизу.
   Конвертация идёт в фоновом потоке — окно остаётся отзывчивым.

## Таблица СК (параметры из R-скрипта v21)

| Пресет | PROJ-строка |
|---|---|
| WGS84 | `EPSG:4326` |
| МГГТ Москвы (x_0=16.098, y_0=14.512) | `+proj=tmerc +lat_0=55.66666666667 +lon_0=37.5 +k=1 +x_0=16.098 +y_0=14.512 +ellps=bessel +towgs84=316.151,78.924,589.650,-1.57273,2.69209,2.34693,8.4507 +units=m +no_defs` |
| Moscow_bessel ДГИ (x_0=0, y_0=0) | `+proj=tmerc +lat_0=55.66666666666666 +lon_0=37.5 +k=1 +x_0=0 +y_0=0 +a=6377397.0 +rf=299.15 +towgs84=316.151,78.924,589.650,-1.57273,2.69209,2.34693,8.4507 +units=m +no_defs` |
| Moscow_bessel ДГИ (смещение x=7.2, y=16.8) | как выше, но `+x_0=7.2 +y_0=16.8` (ручная поправка по контрольной точке: результат смещается на ~7.2 м к западу и ~16.8 м к югу) |
| МСК Борщевика (x_0=1250000, y_0=-1050000) | `+proj=tmerc +lat_0=0 +lon_0=37.5 +k=1 +x_0=1250000 +y_0=-1050000 +ellps=krass +towgs84=23.57,-140.95,-79.8,0,0,0,0 +units=m +no_defs` |
| Пользовательская | любая PROJ-строка / `EPSG:код` из поля ввода |

**Автоопределение**: если рядом с `.shp` лежит `.prj` (WKT) с паттерном
`Moscow_bessel`/`Bessel_Moscow`, центральным меридианом 37.5, широтой
начала 55.66 и нулевыми ложными востоком/севером — предлагается пресет
«Moscow_bessel ДГИ» (в `.prj` заказчика нет датумного сдвига, пресет
добавляет известный MGGT TOWGS84).

## Как идёт конвертация

- **вектор → SHP/GeoJSON/GPKG/DXF**: `ogr2ogr` с `-s_srs`/`-t_srs`
  (каждый аргумент — отдельный элемент списка, пути с пробелами и
  кириллицей безопасны);
- **`.dwg` на входе**: сначала ODA File Converter (DWG → DXF), затем
  DXF конвертируется как вектор; временная копия создаётся под
  ASCII-именем (ODA ненадёжен с кириллицей);
- **вектор → DWG**: `ogr2ogr` (DXF) → оформление (ezdxf) → ODA File
  Converter (DXF → DWG, ACAD2018). Если ODA не найден, выводится
  понятное сообщение и сохраняется DXF;
- **разбивка по полю**: данные перепроецируются в промежуточный GeoJSON,
  затем разбиваются по уникальным значениям поля, и на каждое значение
  создаётся свой DWG/DXF (+ свой XLSX).

```bash
python -m unittest discover -s tests -v
```

Тесты `crs.py` и `features.py` не требуют внешних библиотек;
смоук-тест DXF автоматически пропускается, если не установлены
ezdxf/openpyxl.

## Замечания

- Для DXF-экспорта `ogr2ogr` нуждается в `GDAL_DATA` (файл `header.dxf`);
  приложение ищет его автоматически рядом с ogr2ogr (как R-скрипт).
- ACI-код цвета в XLSX подбирается как ближайший к true color
  (по настоящей таблице ACI при наличии ezdxf).
- Категориальная палитра: первые 15 цветов взяты из R-скрипта
  (`.deterministic_hex`), 5 добавлены до полных 20 (matplotlib tab20).
